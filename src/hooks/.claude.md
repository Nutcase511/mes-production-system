# src/hooks/

## 目录用途
自定义 React Hooks 目录，存放可复用的逻辑封装和状态管理 hooks。

## 主要内容

### Hooks 列表
- `accessibility.ts` / `useAccessibility.ts` - 无障碍功能
- `animation.ts` / `useAnimation.ts` - 动画控制
- `index.ts` - Hooks 导出入口
- `useApi.ts` - API 请求封装
- `useFilteredMenu.ts` - 过滤菜单
- `useMockData.ts` - 模拟数据
- `useProduction.ts` - 生产业务逻辑
- `useRealDataPage.tsx` - 真实数据页面
- `useTableData.ts` - 表格数据处理

## Hooks 分类

### 数据获取 Hooks
- `useApi` - 通用 API 请求
- `useRealDataPage` - 页面数据加载
- `useTableData` - 表格数据管理
- `useProduction` - 生产数据获取

### UI 交互 Hooks
- `useAnimation` - 动画效果
- `useAccessibility` - 无障碍功能
- `useFilteredMenu` - 菜单过滤

### 测试 Hooks
- `useMockData` - 开发测试数据

## Hooks 设计原则
- 单一职责
- 可复用性
- 清晰的命名（use 前缀）
- 类型安全的参数和返回值
- 良好的错误处理

## 技术要点
- 使用 TypeScript 定义参数和返回类型
- 支持 React 依赖数组优化
- 提供 cleanup 函数（如需要）
- 处理 loading 和 error 状态
- 支持取消请求（如需要）

## 与其他目录的关系
- 被多个 `pages/` 和 `components/` 使用
- 依赖 `services/` 进行数据交互
- 可能使用 `contexts/` 访问全局状态
- 使用 `lib/` 中的工具函数

## 注意事项
- 避免 Hooks 嵌套过深
- 提供清晰的文档和使用示例
- 考虑性能优化（useMemo、useCallback）
- 遵循 React Hooks 规则
- 不要在条件语句中使用 Hooks
