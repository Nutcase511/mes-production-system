# src/pages/system/

## 目录用途
系统管理模块页面目录，包含组织架构、物料、工具等基础数据管理页面。

## 主要内容
- `OrganizationPage.tsx` - 组织架构管理
- `MaterialPage.tsx` - 物料管理
- `ToolPage.tsx` - 工具管理

## 页面功能

### 组织架构管理 (OrganizationPage)
- 部门管理
- 员工管理
- 角色管理
- 权限管理

### 物料管理 (MaterialPage)
- 物料基础信息
- 物料分类管理
- 物料规格管理
- 物料供应商管理

### 工具管理 (ToolPage)
- 工具基础信息
- 工具分类管理
- 工具规格管理
- 工具供应商管理

## 技术要点
- 使用 SystemLayout 统一布局
- 使用 AIRIOT SDK 访问系统数据
- 支持系统数据的版本管理
- 提供系统数据的导入导出
- 集成权限控制

## 与其他目录的关系
- 使用 `components/` 中的表格和表单组件
- 使用 `services/` 中的系统相关服务
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 系统数据是基础数据，确保数据准确性
- 提供系统数据的权限控制
- 支持系统数据的审计日志
- 处理系统数据变更的影响
- 确保系统数据的安全性
