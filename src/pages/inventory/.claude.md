# src/pages/inventory/

## 目录用途
库存管理模块页面目录，包含库存、领料、入库、采购等相关页面。

## 主要内容
- `InventoryPage.tsx` - 库存总览页面
- `MaterialRequisitionPage.tsx` - 物料领用页面
- `ProductInboundPage.tsx` - 成品入库页面
- `SemiFinishedInboundPage.tsx` - 半成品入库页面
- `PurchaseOrderPage.tsx` - 采购订单页面
- `InventoryDetailPage.tsx` - 库存详情页面
- `InventoryTransactionPage.tsx` - 库存流水页面
- `InventoryLocationPage.tsx` - 库位管理页面
- `WarehouseTransferPage.tsx` - 仓库调拨页面
- `ScrapManagementPage.tsx` - 报废管理页面
- `WarehouseCoordinationPage.tsx` - 仓库协同页面

## 页面功能

### 库存总览 (InventoryPage)
- 库存实时查询
- 库存分类统计
- 库存预警提示
- 库存数据分析

### 物料领用 (MaterialRequisitionPage)
- 领料单创建
- 领料审批流程
- 领料记录查询
- 领料统计分析

### 成品入库 (ProductInboundPage)
- 成品入库单创建
- 入库质检流程
- 入库记录查询
- 入库统计分析

### 半成品入库 (SemiFinishedInboundPage)
- 半成品入库单创建
- 入库质检流程
- 入库记录查询
- 入库统计分析

### 采购订单 (PurchaseOrderPage)
- 采购订单创建
- 采购审批流程
- 采购订单跟踪
- 采购统计分析

### 库位管理 (InventoryLocationPage)
- 库位信息管理
- 库位分配规则
- 库位利用率分析
- 库位优化建议

## 技术要点
- 使用 InventoryLayout 统一布局
- 使用 AIRIOT SDK 访问库存数据
- 支持库存数据实时更新
- 提供库存数据的导入导出
- 集成库存预警机制

## 与其他目录的关系
- 使用 `components/` 中的表格和表单组件
- 使用 `services/inventory.service.ts` 获取数据
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 库存数据可能较大，注意性能优化
- 提供库存数据的批量操作
- 支持库存二维码扫描
- 处理库存变化的通知
- 确保库存数据的准确性
