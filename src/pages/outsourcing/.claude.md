# src/pages/outsourcing/

## 目录用途
外协管理模块页面目录，包含外协订单、交货、质检等相关页面。

## 主要内容
- `OutsourcingListPage.tsx` - 外协订单列表
- `OutsourcingPendingPage.tsx` - 待处理外协
- `DeliveryPage.tsx` - 外协交货管理
- `QualityCheckPage.tsx` - 外协质检管理
- `CertificatePage.tsx` - 合格证管理

## 页面功能

### 外协订单列表 (OutsourcingListPage)
- 外协订单查询
- 外协订单状态跟踪
- 外协订单统计分析
- 外协订单导出

### 待处理外协 (OutsourcingPendingPage)
- 待审批外协订单
- 待交货外协订单
- 待质检外协订单
- 待确认外协订单

### 外协交货管理 (DeliveryPage)
- 外协交货单创建
- 交货单审批流程
- 交货记录查询
- 交货统计分析

### 外协质检管理 (QualityCheckPage)
- 外协质检任务
- 质检结果记录
- 不合格品处理
- 质检统计分析

### 合格证管理 (CertificatePage)
- 合格证生成
- 合格证查询
- 合格证打印
- 合格证归档

## 技术要点
- 使用 OutsourcingLayout 统一布局
- 使用 AIRIOT SDK 访问外协数据
- 支持外协数据实时更新
- 提供外协数据的导入导出
- 集成外协工作流程

## 与其他目录的关系
- 使用 `components/` 中的表格和表单组件
- 使用 `services/` 中的外协相关服务
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 外协数据可能涉及多个供应商，注意权限控制
- 提供外协数据的批量操作
- 支持外协二维码扫描
- 处理外协状态变化的通知
- 确保外协数据的安全性
