# src/pages/process/

## 目录用途
调度管理模块页面目录，包含工艺路线、工艺规程、工序列表等相关页面。

## 主要内容
- `RouteListPage.tsx` - 工艺路线列表
- `RouteMatchPage.tsx` - 工艺匹配页面
- `ProcessListPage.tsx` - 工艺规程列表

## 页面功能

### 工艺路线列表 (RouteListPage)
- 工艺路线查询
- 工艺路线创建和编辑
- 工艺路线版本管理
- 工艺路线审批流程

### 工艺匹配 (RouteMatchPage)
- 工艺路线自动匹配
- 匹配规则配置
- 匹配结果查看
- 匹配参数调整

### 工艺规程列表 (ProcessListPage)
- 工艺规程查询
- 工艺规程创建和编辑
- 工艺规程版本管理
- 工艺规程下发

## 业务流程
工艺路线制定 → 工艺规程下发 → 生产跟单生成

## 技术要点
- 使用 ProcessLayout 统一布局
- 使用 AIRIOT SDK 访问工艺数据
- 支持工艺数据版本管理
- 提供工艺数据的导入导出
- 集成工艺匹配算法

## 与其他目录的关系
- 使用 `components/` 中的表格和表单组件
- 使用 `services/` 中的工艺相关服务
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 工艺数据是生产流程的核心，确保数据准确性
- 提供工艺数据的版本控制
- 支持工艺数据的审批流程
- 处理工艺变更的影响
- 确保工艺数据的安全性
