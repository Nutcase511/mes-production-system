# src/pages/equipment/

## 目录用途
设备管理模块页面目录，包含设备监控、管理、维保等相关页面。

## 主要内容
- `EquipmentMonitorPage.tsx` - 设备监控页面
- `EquipmentDetailPage.tsx` - 设备详情页面
- `EquipmentListPage.tsx` - 设备列表页面
- `MaintenancePage.tsx` - 设备维保页面
- `InspectionPage.tsx` - 设备点检页面
- `GaugeInspectionPage.tsx` - 量具点检页面
- `ToolMaintenancePage.tsx` - 工具维保页面
- `ImportEquipmentPage.tsx` - 设备数据导入页面

## 页面功能

### 设备监控 (EquipmentMonitorPage)
- 实时监控设备状态
- 设备运行数据展示
- 设备告警信息
- 设备健康度分析

### 设备列表 (EquipmentListPage)
- 设备信息管理
- 设备查询和筛选
- 设备分类管理
- 设备状态统计

### 设备维保 (MaintenancePage)
- 维保计划管理
- 维保记录查看
- 维保工单处理
- 维保提醒设置

### 设备点检 (InspectionPage)
- 点检计划制定
- 点检任务执行
- 点检记录管理
- 点检结果分析

### 量具点检 (GaugeInspectionPage)
- 量具信息管理
- 量具点检计划
- 点检记录管理
- 量具校准提醒

### 工具维保 (ToolMaintenancePage)
- 工具信息管理
- 工具维保计划
- 维保记录管理
- 工具使用统计

## 技术要点
- 使用 EquipmentLayout 统一布局
- 使用 AIRIOT SDK 访问设备数据
- 支持设备状态实时更新
- 提供设备数据导入导出
- 集成设备点检流程

## 与其他目录的关系
- 使用 `components/` 中的表格和表单组件
- 使用 `services/equipment.service.ts` 获取数据
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 设备数据可能较大，注意性能优化
- 提供设备数据的批量操作
- 支持设备二维码扫描
- 处理设备状态变化的通知
- 确保设备数据的安全性
