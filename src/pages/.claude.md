# src/pages/

## 目录用途
页面组件目录，存放所有页面组件，按业务模块组织。

## 主要内容

### 业务模块目录
- `dashboard/` - 看板模块
- `equipment/` - 设备管理模块
- `inventory/` - 库存管理模块
- `layout/` - 布局组件
- `outsourcing/` - 外协管理模块
- `process/` - 调度管理模块
- `production/` - 生产管理模块
- `quality/` - 质量管理模块
- `system/` - 系统管理模块
- `test/` - 测试页面

### 根级页面文件
- `LoginPage.tsx` - 登录页面
- `NotFoundPage.tsx` - 404 页面
- `ForbiddenPage.tsx` - 403 页面

## 页面开发模式

### 标准页面结构
```tsx
import { TableView } from '@/components/DataTable'
import { useModelList } from '@airiot/client'

export function MyPage() {
  const { items, loading } = useModelList('table-id')

  return (
    <TableView tableId="table-id">
      {/* 页面内容 */}
    </TableView>
  )
}
```

### 生产控制页面布局
- 左侧：工单列表（useModelList 获取数据）
- 右侧：操作区域（设备点检、验证、状态控制等卡片）

### 路由保护
- 使用 `ProtectedRoute` 组件包裹需要认证的页面
- 使用 `AuthContext.hasPermission()` 检查权限
- 无权限时跳转到 `/403`

## 技术要点
- 使用 AIRIOT SDK 的 hooks 访问数据
- 遵循深蓝科技风主题
- 使用统一的 Layout 组件
- 支持响应式设计
- 处理 loading 和 error 状态

## 与其他目录的关系
- 使用 `components/` 中的组件
- 使用 `services/` 进行数据交互
- 使用 `hooks/` 中的自定义 hooks
- 使用 `contexts/` 访问全局状态
- 在 `router.tsx` 中注册路由

## 注意事项
- 每个页面文件使用大驼峰命名（如 `OrderListPage.tsx`）
- 页面组件要导出为命名导出
- 提供页面级错误处理
- 考虑页面的性能优化
- 支持页面刷新和数据重新加载
