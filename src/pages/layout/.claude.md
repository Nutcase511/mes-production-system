# src/pages/layout/

## 目录用途
布局组件目录，包含各种页面布局组件。

## 主要内容
- `ProductionLayout.tsx` - 生产管理布局
- `QualityLayout.tsx` - 质量管理布局
- `InventoryLayout.tsx` - 库存管理布局
- `EquipmentLayout.tsx` - 设备管理布局
- `ProcessLayout.tsx` - 调度管理布局
- `OutsourcingLayout.tsx` - 外协管理布局
- `SystemLayout.tsx` - 系统管理布局

## 布局功能

### 生产布局 (ProductionLayout)
- 生产管理模块的统一布局
- 包含顶部导航和侧边栏
- 支持面包屑导航

### 质量布局 (QualityLayout)
- 质量管理模块的统一布局
- 包含顶部导航和侧边栏
- 支持面包屑导航

### 库存布局 (InventoryLayout)
- 库存管理模块的统一布局
- 包含顶部导航和侧边栏
- 支持面包屑导航

## 技术要点
- 使用 React Router 的 Outlet 渲染子路由
- 提供统一的页面结构
- 支持响应式设计
- 遵循深蓝科技风主题

## 与其他目录的关系
- 被 `router.tsx` 使用
- 包裹 `pages/` 中对应模块的页面
- 使用 `components/` 中的导航组件

## 注意事项
- 保持布局的一致性
- 提供良好的用户体验
- 支持页面缓存
- 处理布局的响应式
