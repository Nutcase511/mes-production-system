# src/pages/dashboard/

## 目录用途
看板模块页面目录，包含各种数据可视化看板页面。

## 主要内容
- `DashboardPage.tsx` - 主看板页面
- `Dashboard2Page.tsx` - 车间大屏页面
- `ProductionLinePage.tsx` - 产线监控页面
- `IoTPage.tsx` - IoT 大屏页面
- `FactoryDataPage.tsx` - 数据可视化页面
- `EquipmentStatusPage.tsx` - 设备状态页面

## 页面功能

### 主看板 (DashboardPage)
- 生产概览
- 订单状态
- 设备运行状态
- 质量指标
- 库存概况

### 车间大屏 (Dashboard2Page)
- 车间实时监控
- 生产进度展示
- 异常报警
- 数据可视化

### 产线监控 (ProductionLinePage)
- 产线运行状态
- 产量统计
- 设备利用率
- 生产效率分析

### IoT 大屏 (IoTPage)
- IoT 设备监控
- 实时数据展示
- 设备连接状态
- 数据采集分析

### 数据可视化 (FactoryDataPage)
- 生产数据分析
- 趋势图表
- 统计报表
- 数据钻取

### 设备状态 (EquipmentStatusPage)
- 设备运行状态
- 设备健康度
- 维保提醒
- 设备利用率

## 技术要点
- 使用 echarts 和 recharts 绘制图表
- 使用 AIRIOT SDK 获取实时数据
- 支持数据自动刷新
- 响应式布局设计
- 深蓝科技风主题

## 与其他目录的关系
- 使用 `components/` 中的图表组件
- 使用 `services/` 获取数据
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 考虑大数据量的性能优化
- 提供数据加载状态
- 处理数据更新和刷新
- 支持图表交互
- 确保在大屏上的显示效果
