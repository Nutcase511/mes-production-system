# src/pages/quality/

## 目录用途
质量管理模块页面目录，包含首检、终检、SPC、追溯、返修、报废等相关页面。

## 主要内容
- `FirstCheckPage.tsx` - 首检页面
- `FinalCheckPage.tsx` - 终检页面
- `FinalInspectionPage.tsx` - 成品终检
- `SPCPage.tsx` - SPC 统计过程控制
- `TracePage.tsx` - 生产追溯
- `RepairOrderPage.tsx` - 返修单管理
- `ScrapOrderPage.tsx` - 报废单管理

## 页面功能

### 首检 (FirstCheckPage)
- 首检任务管理
- 首检数据记录
- 首检结果分析
- 首检合格判定

### 终检 (FinalCheckPage)
- 终检任务管理
- 终检数据记录
- 终检结果分析
- 终检合格判定

### 成品终检 (FinalInspectionPage)
- 成品终检任务
- 终检数据记录
- 终检结果分析
- 终检合格判定

### SPC 统计过程控制 (SPCPage)
- SPC 数据采集
- SPC 图表分析
- 过程能力分析
- 控制图监控

### 生产追溯 (TracePage)
- 生产批次追溯
- 物料追溯
- 工序追溯
- 质量追溯

### 返修单管理 (RepairOrderPage)
- 返修单创建
- 返修流程管理
- 返修记录查询
- 返修统计分析

### 报废单管理 (ScrapOrderPage)
- 报废单创建
- 报废流程管理
- 报废记录查询
- 报废统计分析

## 业务流程
试生产控制 → 首检 → 正式生产 → 终检 → 成品入库

## 技术要点
- 使用 QualityLayout 统一布局
- 使用 AIRIOT SDK 访问质量数据
- 支持质量数据实时更新
- 提供质量数据的导入导出
- 集成质量分析算法

## 与其他目录的关系
- 使用 `components/` 中的表格和表单组件
- 使用 `services/` 中的质量相关服务
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 质量数据是产品质量的保障，确保数据准确性
- 提供质量数据的实时监控
- 支持质量异常的及时处理
- 处理质量标准变更的影响
- 确保质量数据的安全性
