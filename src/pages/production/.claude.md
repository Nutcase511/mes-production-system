# src/pages/production/

## 目录用途
生产管理模块页面目录，包含订单、工单、跟单、试产、正式生产等相关页面。

## 主要内容
- `ProductionNoticePage.tsx` - 生产通知
- `OrderListPage.tsx` - 订单列表
- `PreparationChecklistPage.tsx` - 准备状态检查
- `TrialProductionControlPage.tsx` - 试生产控制
- `ProductionPage.tsx` - 正式生产
- `WorkOrderPage.tsx` - 生产跟单
- `WorkTimePage.tsx` - 工时核销
- `DevelopmentPage.tsx` - 研发管理
- `WorkReportPage.tsx` - 工作汇报
- `SchedulingPage.tsx` - 生产调度
- `LaborStandardPage.tsx` - 工时标准
- `LaborReportPage.tsx` - 工时报表
- `DispatchRulePage.tsx` - 派工规则
- `WorkTimeApprovalPage.tsx` - 工时审批

## 页面功能

### 订单列表 (OrderListPage)
- 订单查询和管理
- 订单状态跟踪
- 订单统计分析
- 订单导入导出

### 准备状态检查 (PreparationChecklistPage)
- 准备检查清单
- 检查项配置
- 检查结果记录
- 检查统计分析

### 试生产控制 (TrialProductionControlPage)
- 试生产任务管理
- 试产数据记录
- 试产结果分析
- 试产转正式

### 正式生产 (ProductionPage)
- 生产任务执行
- 生产数据采集
- 生产进度跟踪
- 生产异常处理

### 生产跟单 (WorkOrderPage)
- 工单创建和管理
- 工单状态跟踪
- 工单统计分析
- 工单打印

### 工时核销 (WorkTimePage)
- 工时记录
- 工时审核
- 工时统计分析
- 工时报表

## 业务流程
订单接入 → 工艺路线制定 → 工艺规程下发 → 生产跟单生成 → 准备状态检查 → 领料执行 → 试生产控制 → 首检 → 正式生产 → 终检 → 成品入库 → 工时核销

## 技术要点
- 使用 ProductionLayout 统一布局
- 使用 AIRIOT SDK 访问生产数据
- 支持生产数据实时更新
- 提供生产数据的导入导出
- 集成生产控制流程

## 与其他目录的关系
- 使用 `components/` 中的表格和表单组件
- 使用 `services/` 中的生产相关服务
- 使用 `hooks/` 中的自定义 hooks
- 在 `router.tsx` 中注册路由

## 注意事项
- 生产数据是核心业务数据，确保数据准确性
- 提供生产数据的实时监控
- 支持生产异常的及时处理
- 处理生产状态变化的通知
- 确保生产数据的安全性
