# src/app/

## 目录用途
应用级别的组件和配置文件，通常包含全局应用逻辑和初始化代码。

## 主要内容

### 子目录
- `components/` - 应用级通用组件
- `config/` - 应用配置

## 典型使用场景
- 全局应用状态管理
- 应用级别的布局组件
- 应用初始化配置
- 全局错误处理
- 全局事件监听

## 技术要点
- 组件应具有高度可复用性
- 避免依赖具体业务逻辑
- 优先使用 TypeScript 接口定义 Props
- 考虑性能优化（useMemo、useCallback）

## 与其他目录的关系
- 依赖 `components/` 中的基础组件
- 使用 `lib/` 中的工具函数
- 通过 `contexts/` 访问全局状态
- 被多个 `pages/` 中的页面使用

## 注意事项
- 保持组件的通用性和独立性
- 避免在应用级组件中硬编码业务逻辑
- 考虑组件的可测试性
- 提供清晰的 Props 类型定义
