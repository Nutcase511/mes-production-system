# src/config/

## 目录用途
配置文件目录，存放项目的各种配置信息，包括权限配置、表映射、业务规则等。

## 主要内容

### 配置文件
- `permissions.ts` - 权限控制配置
  - 用户角色权限映射
  - 导航权限规则
  - 页面访问权限

- `preparation-checklist.ts` - 准备检查清单配置
  - 检查项目定义
  - 检查规则配置
  - 默认值设置

- `production-type-rules.ts` - 生产类型规则配置
  - 生产类型定义
  - 工艺规则配置
  - 状态转换规则

- `table-mappings.ts` - 表映射配置
  - AIRIOT 表 ID 映射
  - 字段映射关系
  - 表关联关系

- `tables.config.ts` - 表配置
  - 表结构定义
  - 字段配置
  - 验证规则

## 配置特点
- 集中管理配置信息
- 类型安全的配置定义
- 支持环境变量
- 可扩展的配置结构

## 技术要点
- 使用 TypeScript 接口定义配置类型
- 导出常量而非函数（提高性能）
- 支持配置验证
- 提供默认值
- 支持配置的动态加载

## 与系统的关系
- 被 `pages/` 中的页面引用
- 被 `services/` 中的服务使用
- 被 `contexts/` 中的上下文使用
- 可能被 `router.tsx` 使用

## 注意事项
- 不要在配置文件中存放敏感信息
- 配置变更需要考虑向后兼容
- 提供清晰的配置文档
- 考虑配置的版本管理
- 避免在配置文件中编写复杂逻辑
