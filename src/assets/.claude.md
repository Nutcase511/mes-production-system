# src/assets/

## 目录用途
存放静态资源文件，包括图片、字体、图标、JSON 数据文件等。

## 主要内容
- 图片资源（PNG、JPG、SVG 等）
- 字体文件
- 图标文件
- 静态数据文件（JSON）
- 其他媒体资源

## 文件组织建议
```
assets/
├── images/          # 图片资源
│   ├── logos/      # Logo 文件
│   ├── icons/      # 图标
│   └── backgrounds/ # 背景图
├── fonts/           # 字体文件
├── data/            # 静态数据
└── media/           # 其他媒体文件
```

## 技术要点
- 图片文件建议使用 WebP 格式（更好的压缩）
- SVG 图标可以内联到组件中
- 大型资源文件考虑使用 CDN
- 敏感数据不要放在此目录

## 与系统的关系
- 通过 Vite 的静态资源处理机制导入
- 在组件中使用 import 语句引用
- 支持热更新（开发环境）
- 构建时会被处理和优化

## 注意事项
- 不要将大文件（>1MB）放入此目录
- 避免使用过大的图片影响加载性能
- 资源文件命名使用 kebab-case
- 考虑使用图片懒加载技术
