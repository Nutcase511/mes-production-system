# src/models/

## 目录用途
AIRIOT 数据模型定义目录，存放 AIRIOT 平台的数据模型注册和定义。

## 主要内容

### index.ts
数据模型注册入口文件，导出所有数据模型定义。

## 数据模型定义
AIRIOT 平台使用 Model 来定义数据表结构和字段类型。每个 Model 对应平台中的一个表。

## 典型 Model 结构
```typescript
import { Model } from '@airiot/client'

export const UserModel: Model = {
  id: 'user',  // 模型 ID
  name: '用户', // 模型名称
  fields: [    // 字段定义
    {
      id: 'username',
      name: '用户名',
      type: 'string',
      required: true,
    },
    // ... 其他字段
  ],
}
```

## 字段类型
- `string` - 字符串
- `number` - 数字
- `boolean` - 布尔值
- `date` - 日期
- `datetime` - 日期时间
- `select` - 选择
- `relate` - 关联
- `file` - 文件
- 等等...

## 使用方式
```typescript
// 在 main.tsx 中注册
import { registerModels } from '@/models'

registerModels()

// 在组件中使用
import { useModel } from '@airiot/client'

function MyComponent() {
  const model = useModel('user')
  // ...
}
```

## 与系统的关系
- 在 `main.tsx` 中注册所有模型
- 被 AIRIOT SDK 使用
- 在 `services/` 中通过模型 ID 访问数据
- 在 `pages/` 中通过 hooks 使用模型数据

## 注意事项
- 模型 ID 必须与平台中的表 ID 一致
- 字段定义要准确反映表结构
- 字段类型要与平台定义一致
- 保持模型定义的更新
- 提供模型文档
