# src/blocks/

## 目录用途
业务块组件目录，存放可复用的复杂业务逻辑组件。这些组件比普通 components 更加复杂，包含特定的业务逻辑。

## 主要内容

### 业务块列表
- `process-flow/` - 生产流程可视化组件
- `production-table/` - 生产数据表格组件
- `quality-form/` - 质量检验表单组件
- `route-match/` - 工艺路线匹配组件
- `spc-chart/` - SPC 统计过程控制图表
- `status-badge/` - 状态徽章组件
- `work-order-card/` - 工单卡片组件

## 组件特征
- 包含完整的业务逻辑
- 封装复杂的状态管理
- 通常涉及多个 API 调用
- 具有较高的复用价值
- 可能包含子组件

## 技术要点
- 使用自定义 hooks 封装业务逻辑
- 通过 Context 管理组件内部状态
- 使用 TypeScript 定义清晰的接口
- 支持配置化和定制化
- 提供良好的错误处理

## 与其他目录的关系
- 依赖 `services/` 进行数据交互
- 使用 `components/` 中的基础组件
- 可能使用 `hooks/` 中的自定义 hooks
- 被多个 `pages/` 中的页面复用

## 注意事项
- 保持组件的单一职责
- 提供清晰的 Props 文档
- 考虑组件的性能优化
- 支持响应式设计
- 避免过度耦合具体页面逻辑
