# src/blocks/route-match/

## 目录用途
工艺路线匹配组件目录，包含工艺路线自动匹配的相关组件。

## 主要内容
- 路线匹配组件
- 匹配规则组件
- 匹配结果组件
- 匹配参数组件

## 组件功能
- 路线自动匹配
- 匹配规则配置
- 匹配结果展示
- 匹配参数调整

## 技术要点
- 使用 AIRIOT SDK 访问工艺数据
- 支持匹配算法
- 支持匹配结果可视化
- 支持匹配参数调整

## 与其他目录的关系
- 被 `pages/process/RouteMatchPage` 使用
- 使用 `components/` 中的基础组件
- 使用 `services/` 中的工艺相关服务

## 注意事项
- 提供良好的用户体验
- 支持匹配结果的可视化
- 考虑匹配算法的性能
- 支持匹配规则的配置化
