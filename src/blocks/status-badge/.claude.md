# src/blocks/status-badge/

## 目录用途
状态徽章组件目录，包含各种状态展示的徽章组件。

## 主要内容
- 状态徽章组件
- 状态标签组件
- 状态指示器组件

## 组件功能
- 状态展示
- 状态颜色映射
- 状态文本展示
- 状态图标展示

## 技术要点
- 使用 React 实现组件
- 支持自定义颜色
- 支持自定义图标
- 支持自定义文本
- 遵循深蓝科技风主题

## 与其他目录的关系
- 被 `pages/` 和 `components/` 中的组件使用
- 使用 `lib/utils.ts` 中的工具函数

## 注意事项
- 提供一致的视觉风格
- 支持主题定制
- 支持响应式设计
- 提供清晰的文档
