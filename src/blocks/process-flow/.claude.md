# src/blocks/process-flow/

## 目录用途
生产流程可视化组件目录，包含生产流转流程的可视化展示组件。

## 主要内容
- 生产流程图组件
- 流程节点组件
- 流程连线组件
- 流程状态组件

## 组件功能
- 生产流程可视化
- 流程状态展示
- 流程节点交互
- 流程进度跟踪

## 技术要点
- 使用 ECharts 绘制流程图
- 支持流程状态实时更新
- 支持流程节点点击交互
- 支持流程进度动画

## 与其他目录的关系
- 被 `pages/` 中的页面使用
- 使用 `components/` 中的基础组件
- 使用 `services/` 中的流程相关服务

## 注意事项
- 提供良好的用户体验
- 支持响应式设计
- 考虑组件的性能
- 支持流程配置化
