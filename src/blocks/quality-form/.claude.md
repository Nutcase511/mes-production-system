# src/blocks/quality-form/

## 目录用途
质量检验表单组件目录，包含质量检验相关的表单组件。

## 主要内容
- 首检表单组件
- 终检表单组件
- 质检表单组件
- 检验项目组件

## 组件功能
- 检验数据录入
- 检验结果判定
- 检验数据验证
- 检验数据保存

## 技术要点
- 使用 React Hook Form 管理表单
- 支持表单验证
- 支持动态表单项
- 支持表单数据绑定
- 支持表单提交

## 与其他目录的关系
- 被 `pages/quality/` 中的页面使用
- 使用 `components/airiot/form-*` 中的表单组件
- 使用 `services/` 中的质量相关服务

## 注意事项
- 提供良好的用户体验
- 支持表单验证
- 支持表单数据持久化
- 考虑表单的性能
