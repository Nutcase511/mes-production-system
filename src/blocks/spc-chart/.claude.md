# src/blocks/spc-chart/

## 目录用途
SPC 统计过程控制图表组件目录，包含 SPC 相关的图表和分析组件。

## 主要内容
- SPC 控制图组件
- 过程能力分析组件
- 控制限计算组件
- 数据分布图组件

## 组件功能
- SPC 控制图绘制
- 过程能力分析
- 控制限计算
- 数据分布分析
- 异常点检测

## 技术要点
- 使用 ECharts 绘制图表
- 支持实时数据更新
- 支持图表交互
- 支持数据导出
- 支持图表配置

## 与其他目录的关系
- 被 `pages/quality/SPCPage` 使用
- 使用 `components/` 中的图表组件
- 使用 `services/` 中的质量相关服务

## 注意事项
- 提供良好的用户体验
- 支持图表的交互性
- 考虑大数据量的性能
- 支持图表的配置化
