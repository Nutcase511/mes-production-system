# src/blocks/work-order-card/

## 目录用途
工单卡片组件目录，包含工单信息展示的卡片组件。

## 主要内容
- 工单卡片组件
- 工单状态组件
- 工单操作组件

## 组件功能
- 工单信息展示
- 工单状态展示
- 工单操作
- 工单详情查看

## 技术要点
- 使用 React 实现组件
- 支持卡片布局
- 支持状态展示
- 支持操作按钮
- 遵循深蓝科技风主题

## 与其他目录的关系
- 被 `pages/production/WorkOrderPage` 使用
- 使用 `components/` 中的基础组件
- 使用 `services/` 中的生产相关服务

## 注意事项
- 提供良好的用户体验
- 支持卡片交互
- 考虑组件的性能
- 支持响应式设计
