# src/blocks/production-table/

## 目录用途
生产数据表格组件目录，包含生产相关数据的表格展示组件。

## 主要内容
- 生产数据表格组件
- 生产统计表格组件
- 生产对比表格组件

## 组件功能
- 生产数据展示
- 生产数据排序
- 生产数据筛选
- 生产数据分页
- 生产数据导出

## 技术要点
- 使用 React 实现表格组件
- 支持虚拟滚动（大数据量）
- 支持自定义列
- 支持行选择
- 支持行操作

## 与其他目录的关系
- 被 `pages/production/` 中的页面使用
- 使用 `components/DataTable/` 中的基础组件
- 使用 `services/` 中的生产相关服务

## 注意事项
- 考虑大数据量的性能优化
- 提供良好的用户体验
- 支持响应式设计
- 提供清晰的文档
