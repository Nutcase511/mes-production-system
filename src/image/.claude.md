# src/image/

## 目录用途
图片资源目录，存放项目中的图片文件。

## 主要内容
- 应用图标
- 产品图片
- 设备图片
- 用户头像
- 其他图片资源

## 文件组织建议
```
image/
├── logos/        # Logo 文件
├── icons/        # 图标
├── products/     # 产品图片
├── equipment/    # 设备图片
├── users/        # 用户头像
└── others/       # 其他图片
```

## 图片格式建议
- **Logo**: SVG（矢量图，可缩放）
- **图标**: SVG 或 PNG
- **照片**: WebP（更好的压缩）或 JPG
- **透明背景**: PNG

## 技术要点
- 使用 Vite 的静态资源处理
- 支持图片压缩和优化
- 支持热更新（开发环境）
- 构建时自动处理

## 使用方式
```tsx
// 直接导入
import logo from '@/image/logos/app-logo.svg'

// 使用
<img src={logo} alt="App Logo" />
```

## 与系统的关系
- 被 `pages/` 和 `components/` 引用
- 通过 Vite 构建系统处理
- 支持图片懒加载

## 注意事项
- 不要存放过大的图片文件
- 使用合适的图片格式
- 压缩图片以减少文件大小
- 考虑使用 CDN 托管大型图片
- 图片命名使用 kebab-case
