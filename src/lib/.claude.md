# src/lib/

## 目录用途
工具库目录，存放通用的工具函数、辅助函数和第三方库的初始化代码。

## 主要内容

### airiot-client.ts
AIRIOT SDK 初始化配置，设置项目 ID 和 API 基础路径。

### utils.ts
通用工具函数集合。

#### 主要函数
- `cn()` - classnames 合并工具，支持 Tailwind 类名合并
- `formatDate()` - 日期格式化
- `formatDateTime()` - 日期时间格式化
- `getStatusVariant()` - 状态变体映射（颜色映射）
- 其他工具函数

## 工具函数设计原则
- 纯函数（无副作用）
- 输入输出明确
- 类型安全
- 性能优化
- 提供清晰的文档

## 技术要点
- 使用 TypeScript 定义函数签名
- 提供默认参数
- 处理边界情况
- 提供 JSDoc 注释
- 考虑函数的可测试性

## 与其他目录的关系
- 被整个项目广泛使用
- 被 `hooks/`、`services/`、`components/` 等引用
- 不依赖其他业务目录（保持独立性）

## 注意事项
- 保持工具函数的通用性
- 避免在工具函数中包含业务逻辑
- 提供单元测试
- 文档化函数的使用方法
- 考虑函数的性能
