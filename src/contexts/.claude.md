# src/contexts/

## 目录用途
React Context 目录，存放全局状态管理和跨组件数据共享的 Context 实现。

## 主要内容

### AuthContext.tsx
认证上下文，提供用户认证相关的全局状态和方法。

#### 提供的功能
- `user` - 当前用户信息
- `isAuthenticated` - 认证状态
- `isLoading` - 加载状态
- `login(username, password)` - 登录方法
- `logout()` - 登出方法
- `hasPermission(permission)` - 权限检查方法

#### 技术实现
- 使用 localStorage 持久化用户信息
- 与 AIRIOT SDK 双同步（setUser）
- 密码使用 SHA1 哈希
- 支持角色权限映射
- 自动恢复登录状态

#### 使用方式
```tsx
import { useAuth } from '@/contexts/AuthContext'

function MyComponent() {
  const { user, isAuthenticated, hasPermission } = useAuth()

  if (!isAuthenticated) return <LoginPage />
  if (!hasPermission('admin')) return <ForbiddenPage />

  return <div>欢迎, {user.name}</div>
}
```

## Context 设计原则
- 保持 Context 的单一职责
- 避免在 Context 中存储过多数据
- 提供类型安全的方法
- 考虑性能优化（使用 useMemo）
- 提供清晰的文档

## 技术要点
- 使用 React.createContext 创建 Context
- 提供自定义 Hook 访问 Context（useXxx）
- 在组件根部提供 Context Provider
- 处理 Context 的默认值
- 支持 TypeScript 类型检查

## 与其他目录的关系
- 被 `App.tsx` 在根部提供
- 被 `pages/` 和 `components/` 中的组件使用
- 依赖 `services/` 进行数据交互
- 可能使用 `hooks/` 中的自定义 hooks

## 注意事项
- 避免在 Context 中进行复杂的计算
- 不要在 Context 中存放不必要的状态
- 提供 Context 错误边界处理
- 考虑 Context 的拆分（避免单一 Context 过大）
- 文档化 Context 的使用方法
