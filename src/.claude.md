# src/

## 目录用途
MES 生产管理系统前端项目的源代码根目录，包含所有业务逻辑、组件、配置和资源文件。

## 主要内容

### 核心文件
- `main.tsx` - 应用入口，初始化 AIRIOT 客户端并注册数据模型
- `App.tsx` - 根组件，包含 AuthProvider、RouterProvider 和 ToastContainer
- `router.tsx` - 路由配置，定义所有页面路由和导航结构
- `index.css` - 全局样式，Tailwind CSS v4 配置和主题定义

### 目录结构
- `app/` - 应用相关组件和配置
- `assets/` - 静态资源（图片、字体等）
- `blocks/` - 业务块组件（可复用的复杂业务逻辑组件）
- `components/` - 通用组件库
- `config/` - 配置文件（权限、表映射、表配置）
- `contexts/` - React Context（认证、主题等）
- `hooks/` - 自定义 React Hooks
- `lib/` - 工具库和辅助函数
- `models/` - AIRIOT 数据模型定义
- `pages/` - 页面组件（按业务模块组织）
- `registry/` - AIRIOT 组件注册
- `services/` - API 服务层
- `styles/` - 样式文件
- `types/` - TypeScript 类型定义

## 技术架构

### 技术栈
- **框架**: React 19 + TypeScript 5.9
- **构建**: Vite 8
- **样式**: Tailwind CSS v4
- **UI**: shadcn/ui + Radix UI
- **路由**: react-router-dom 7
- **图表**: echarts + echarts-for-react + recharts
- **平台 SDK**: @airiot/client 1.0.12

### 关键依赖
- **认证**: crypto-js（SHA1 密码哈希）
- **HTTP**: axios
- **状态管理**: React Context
- **表单**: React Hook Form

## 与系统的关系
- 所有前端代码的根目录
- 通过 AIRIOT SDK 与后端平台交互
- 通过 router.tsx 统一管理所有路由和权限
- 通过 AuthContext 统一管理认证状态

## 注意事项
- 所有页面必须包裹在相应的 Layout 组件中
- 使用 AIRIOT SDK 的 hooks（useModel、useModelList 等）访问数据
- 遵循深蓝科技风暗色主题设计规范
- 使用 TypeScript 严格模式，确保类型安全
- 所有 API 调用通过 services 层封装
