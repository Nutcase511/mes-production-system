# src/types/

## 目录用途
TypeScript 类型定义目录，存放项目中使用的所有类型定义和接口。

## 主要内容

### 类型分类
- API 响应类型
- 数据模型类型
- 组件 Props 类型
- 工具函数类型
- 配置类型
- 业务类型

## 典型类型定义
```typescript
// API 响应类型
export interface ApiResult<T> {
  code: number
  message: string
  data: T
}

// 用户类型
export interface User {
  id: string
  username: string
  name: string
  email?: string
  role: string
  permissions: string[]
}

// 表格数据类型
export interface TableData {
  id: string
  [key: string]: any
}

// 分页类型
export interface Pagination {
  page: number
  pageSize: number
  total: number
}
```

## 类型设计原则
- 使用 interface 定义对象类型
- 使用 type 定义联合类型
- 提供泛型支持
- 使用 readonly 修饰不可变属性
- 提供可选属性（?）

## 与其他目录的关系
- 被整个项目广泛使用
- 被 `services/`、`pages/`、`components/` 引用
- 提供类型安全保障

## 注意事项
- 保持类型定义的准确性
- 提供清晰的类型文档
- 避免使用 any 类型
- 使用泛型提高类型复用性
- 考虑类型的可扩展性
