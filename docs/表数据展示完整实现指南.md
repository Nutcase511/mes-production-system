# 表数据展示完整实现指南

## 📋 概述

在 AIRIOT MES 前端项目中，有两种方式实现表数据展示：

1. **@airiot/client + 自定义 DataGrid** - 当前项目使用的方式
2. **@kesi/view-data-table + ViewModel** - kesi-ui 提供的高级组件

本文档详细说明这两种方式的完整实现流程。

---

## 方式一：@airiot/client + 自定义 DataGrid（当前使用）

### 架构说明

```
Model 组件 (数据管理)
    ↓
useModelList Hook (获取数据)
    ↓
自定义 TableBlock (列定义)
    ↓
DataGrid + DataGridTable (表格渲染)
```

### 完整实现步骤

**可用的 Hooks**：

| Hook | 用途 | 返回值 |
|------|------|--------|
| `useModelList()` | 获取列表数据 | `{ items, loading, fields }` |
| `useModelPagination()` | 分页控制 | `{ items, activePage, changePage }` |
| `useModelGet()` | 获取单条记录 | `{ item, loading, get }` |
| `useModelSave()` | 保存记录 | `{ saveItem, saving }` |
| `useModelDelete()` | 删除记录 | `{ deleteItem, deleting }` |
| `useModelState(key)` | 获取和设置状态 | `[value, setValue]` |

#### 步骤 3: 设置查询条件

```typescript
import { useState, useEffect } from 'react'

function ProductionOrderListContent() {
  const [wheres, setWheres] = useModelState('wheres')
  const [filters, setFilters] = useState({})
  const [searchText, setSearchText] = useState('')

  // ✅ 当筛选条件变化时更新查询
  useEffect(() => {
    const filterConditions: any = {}

    // 添加筛选条件
    Object.entries(filters).forEach(([key, value]) => {
      if (value && value !== 'all') {
        filterConditions[key] = value
      }
    })

    // 添加搜索条件（模糊查询）
    if (searchText) {
      filterConditions['notificationNumber'] = { $like: `%${searchText}%` }
    }

    // ✅ 关键：包装一层 filter
    const newWheres = {
      filter: filterConditions
    }

    setWheres(newWheres)
  }, [filters, searchText, setWheres])

  return <div>...</div>
}
```

**查询条件格式**：

```typescript
// 等值查询
{ filter: { status: '生产中' } }

// 范围查询
{ filter: { issueDate: { $gte: '2026-04-01', $lte: '2026-04-30' } } }

// 模糊查询
{ filter: { notificationNumber: { $like: '%PO%' } } }

// 组合查询
{
  filter: {
    status: '生产中',
    orderType: '1',
    issueDate: { $gte: '2026-04-01' }
  }
}
```

#### 步骤 4: 创建自定义表格组件

**文件**: `src/blocks/production-table/index.tsx`

```typescript
import { DataGrid, DataGridContainer, DataGridTable } from '@/components/ui/data-grid/data-grid'
import type { ColumnDef } from '@tanstack/react-table'
import { useReactTable, getCoreRowModel } from '@tanstack/react-table'

interface ProductionTableBlockProps {
  data: any[]
  loading?: boolean
  schema?: any
  onRowClick?: (row: any) => void
  onEditOrder?: (row: any) => void
  pagination?: {
    current: number
    pageSize: number
    total: number
    onPageChange: (page: number) => void
  }
}

export function ProductionTableBlock({
  data,
  loading,
  schema,
  onRowClick,
  onEditOrder,
  pagination
}: ProductionTableBlockProps) {
  // ✅ 根据动态生成列定义
  const columns: ColumnDef<any>[] = []

  if (schema?.schema?.form && schema.schema.properties) {
    // 排除不需要显示的字段
    const excludedFields = ['upload-single-AE62', 'text-F185', 'auditByOpinion']

    schema.schema.form.forEach((fieldKey: string) => {
      if (excludedFields.includes(fieldKey)) return

      const fieldSchema = schema.schema?.properties?.[fieldKey]
      if (!fieldSchema) return

      // ✅ 定义列
      columns.push({
        accessorKey: fieldKey,
        header: fieldSchema.title || fieldKey,
        size: 150,
        cell: ({ row }) => (
          <div className="truncate" title={row.original[fieldKey]}>
            {renderCellValue(fieldKey, row.original[fieldKey], fieldSchema)}
          </div>
        )
      })
    })
  }

  // ✅ 添加操作列
  columns.push({
    id: 'actions',
    header: '操作',
    size: 150,
    cell: ({ row }) => (
      <div className="flex gap-2">
        <Button size="sm" onClick={() => onEditOrder?.(row.original)}>
          编辑
        </Button>
      </div>
    )
  })

  // ✅ 创建 TanStack Table 实例
  const table = useReactTable({
    data,
    columns,
    getCoreRowModel: getCoreRowModel(),
    enableColumnPinning: true, // 启用列固定
    state: {
      columnPinning: {
        left: [],
        right: ['actions'] // 固定操作列在右侧
      }
    }
  })

  if (loading) {
    return <div>加载中...</div>
  }

  return (
    <DataGrid
      table={table}
      recordCount={pagination?.total || data.length}
      isLoading={loading}
      onRowClick={onRowClick}
      tableLayout={{
        columnsResizable: true,
        columnsPinnable: true,
        headerBackground: true,
        headerSticky: true,
      }}
      tableClassNames={{
        header: 'bg-slate-700/70 [&_th]:text-white',
        headerRow: 'border-slate-700/30 hover:bg-slate-700/20',
        bodyRow: 'border-slate-700/20 hover:bg-slate-700/30',
      }}
    >
      <DataGridContainer border={true}>
        <div className="overflow-x-auto rounded-md">
          <DataGridTable />
        </div>
      </DataGridContainer>

      {pagination && (
        <Pagination
          current={pagination.current}
          pageSize={pagination.pageSize}
          total={pagination.total}
          onPageChange={pagination.onPageChange}
        />
      )}
    </DataGrid>
  )
}
```

### 优缺点

**缺点**：

## 最佳实践建议

### 1. 项目初期

使用 **@kesi/view-data-table**，快速搭建基础功能：

```typescript
<ViewModel tableId="表名" modelName="模型名">
  <ViewDataTable>
    <TableColumn name="字段1" title="标题1" />
    <TableColumn name="字段2" title="标题2" />
  </ViewDataTable>
</ViewModel>
```

### 2. 复杂业务场景

使用 **@airiot/client + 自定义表格**，完全控制：

```typescript
<Model name="表名" modelKey="唯一key">
  <CustomTableBlock />
</Model>
```

### 3. 混合使用

```typescript
// 简单列表用 ViewDataTable
<ViewModel tableId="user" modelName="user">
  <ViewDataTable />
</ViewModel>

// 复杂表格用自定义
<Model name="投产通知单" modelKey="orders">
  <ProductionTableBlock />
</Model>
```

## 关键配置对比

| 功能 | @airiot/client | @kesi/view-data-table |
|------|----------------|----------------------|
| **数据获取** | 手动使用 `useModelList()` | 自动处理 |
| **分页** | 手动使用 `useModelPagination()` | 自动处理 |
| **列定义** | 手动定义 `ColumnDef[]` | 使用 `<TableColumn>` 组件 |
| **列固定** | 设置 `state.columnPinning` | 设置 `fixed="left/right"` |
| **排序** | 需要手动实现 | 自动处理 |
| **行选择** | 需要手动实现 | 内置支持 |
| **代码量** | 较多（~300行） | 较少（~100行） |
| **灵活性** | 高 | 中 |

## 迁移指南

### 从方式一迁移到方式二

1. **替换 Model 为 ViewModel**
   ```typescript
   // 之前
   <Model name="表名" modelKey="key">
     <Content />
   </Model>

   // 之后
   <ViewModel tableId="表名" modelName="key">
     <Content />
   </ViewModel>
   ```

2. **替换自定义表格为 ViewDataTable**
   ```typescript
   // 之前
   <DataGrid table={table}>
     <DataGridTable />
   </DataGrid>

   // 之后
   <ViewDataTable>
     <TableColumn name="字段" title="标题" />
   </ViewDataTable>
   ```

3. **删除不必要的状态管理**
   - 删除 `useModelList`, `useModelPagination` 等调用
   - ViewModel 自动处理数据加载

### 选择建议

- **混合使用**: 根据场景灵活选择
